Nexcess: The WooCommerce and Magento Host That Cranked Its Way to #11 on the Inc. 5000 List

Nexcess has established itself as a prominent player in the managed hosting space over its 23-year history. Operating across 10 global data centers, the company manages over 500,000 websites while maintaining its spot on the Inc. 5000 list for the 11th time. Their expertise shines through specialized services for WordPress, Magento, and WooCommerce, earning them recognition as the "Most Promising Magento Solution Provider 2021."

This article delves into Nexcess's comprehensive offering through several key lenses. We examine their managed hosting architecture, highlighting the technical foundations that support their 500,000+ website management. The article also explores the client portal, showcasing the advanced features that enable intuitive account management and platform integration. Security forms another critical pillar, as we detail the multi-layered approach that protects hosted environments while maintaining performance and flexibility.

From scalable infrastructure to comprehensive domain management, this overview captures the breadth of Nexcess's offerings. The company's commitment to supporting both small businesses and enterprise-level workloads is evident throughout, making their 23 years of experience particularly valuable in today's rapidly evolving digital landscape.

Nexcess Company Background and Recognition

Nexcess's 23 years in the hosting industry have established it as a major player in the CloudOne Digital portfolio. With management of over 500,000 websites across 10 global data centers, the company has built a strong foundation for its various services.

The company's achievements have been recognized through multiple appearances on the Inc. 5000 list, most recently earning its 11th honoree designation. Nexcess specializes in providing best-in-class infrastructure and cloud capabilities tailored to small businesses, entrepreneurs, and enterprise-level workloads.

Managed Hosting Services

Built on 23 years of experience, Nexcess's managed hosting services offer several advantages. The company's suite of services includes WordPress, Magento, and WooCommerce hosting solutions that combine managed environment benefits with robust functionality.

Scalability and Performance

The platform handles traffic spikes through instant autoscaling that bypasses PHP capacity limits. Underpinned by PHP8+, Nginx, and advanced caching, it delivers superior performance while maintaining security and flexibility.

Security Features

Always-on monitoring, Solid Security protocols, server access controls, and advanced DDoS protection form the core security framework. The company's "Most Promising Magento Solution Provider 2021" recognition highlights its prowess in this particular market.

Client Portal Features

The Nexcess Client Portal serves as the primary interface for account management and service control. It offers several key features, including:

  • Multi-account management using single login credentials

  • Comprehensive billing information and payment management

  • Support ticket system for service requests

  • Advanced features forMagento, WordPress, and WooCommerce management

  • Secure access controls with role-based permissions

The portal also supports API integration, allowing script access through API Tokens. For security, users can enable two-factor authentication and manage SSH keys for server access.

Partner Programs

Nexcess operates two primary partner programs: Agency Partner and Affiliate Partner. The Agency Partner program offers premium support, IT management services, and referral commission structures up to 20% of annual referral revenue. The Affiliate Partner program rewards direct sales referrals with $150 commissions per successful purchase.

This detailed program structure, combined with recognized industry awards, positions Nexcess as a comprehensive solution provider in the managed hosting space.

Nexcess Client Portal Features and Functionality

The Nexcess Client Portal streamlines account management through several key features. Users can switch between multiple accounts using a single login, with the most recently visited account displayed by default. To change the default client, users access the corner drop-down menu, select Set Default Client, choose their preferred account, and confirm with Update Default Client.

Customer feedback plays a significant role in platform development through the Suggest an Idea feature, which captures and organizes user suggestions for continuous improvement. The portal's Announcements section keeps users updated on important changes and news.

Essential account management functions include email and password updates, retrieval of Nexcess Account ID and Call-In PIN, and enablement of two-factor authentication for enhanced security. The portal supports multiple team roles - Superuser, Billing, and Technical - with permission settings managed by superusers to control access across all portal content.

For developers and automated systems, the Client Portal offers API integration capabilities detailed in the Nexcess Client Portal API token article. Additional support resources are available through the website's comprehensive documentation library.

The system's security features include regular password resets via the "Forgot Password?" link and secure data protection through SSL encryption, with small lock icons indicating connection security in web browsers. DNS functionality manages website URL translations to IP addresses, with advanced options available after selecting Show More.

The portal provides comprehensive site management tools for WordPress, WooCommerce, and Magento hosting, including domain change management, access logs, and WordPress update functionality. Users can access backup management features through automatic daily site backups stored for 30 days, with the option to create manual backups for local storage.

The home page displays critical account information including the Nexcess Account ID, Call-In PIN, open support tickets, account payment status indicators, and current credit balance. System monitoring tracks the status of essential components such as Support Services, Cloud Container Services, Nexcess Cloud, Platform Operations, and Data Centers & Networks.

Hosting Services and Platform Support

Nexcess operates with a comprehensive hosting architecture that has evolved over 23 years, managing 500,000 websites across 10 global data centers. Their managed hosting services now offer more than just baseline capabilities; they're particularly noted for their specialization in industry-leading platforms, with several key differentiators:

Managed WordPress, Magento, and WooCommerce Hosting

Nexcess has developed specialized hosting solutions for these platforms, building on their extensive experience. Their WordPress hosting includes features like instant autoscaling to bypass PHP capacity limits and advanced caching systems. Notably, their Magento hosting has earned distinction as the "Most Promising Magento Solution Provider 2021."

Core Benefits and Platform Features

The company emphasizes three core benefits: freedom and flexibility, speed and security, and 24/7 expert support. Advanced features include CDN support, container services, and comprehensive logs management through their client portal.

Performance and Scalability

The hosting platform is built on PHP8+,/nginx architecture, with advanced asset caching and integrated CDN capabilities. It's designed to handle traffic spikes with instant autoscaling, allowing sites to scale up or down as needed to meet demand.

Security Infrastructure

The platform employs several layers of security including always-on monitoring, Solid Security protocols, server access controls, and Web Application Firewall (WAF) protection. This robust security framework extends to robust DDoS prevention and malware detection mechanisms.

Domain Management and Registration

Nexcess manages domain registration through OpenSRS, the second-largest domain registrar in the world, ensuring robust and reliable registration processes. The domain validation procedure requires a 15-day email confirmation period, during which users must click a verification link provided by OpenSRS to complete the registration process.

The company prioritizes privacy protection through WHOIS privacy services, which mask personal information including addresses, phone numbers, and names in public domain listings. This enhanced privacy is achieved through authenticated, encrypted data and the use of a protective decoy address structure.

Domain services offered by Nexcess encompass comprehensive management capabilities at no additional cost, including DNS configuration, nameserver transitions, and domain forwarding options. Their team responds quickly to any issues, working to restore service as needed.

The company recommends selecting short, easy-to-spell words related to website content for optimal navigation. While .com remains the most common suffix, Nexcess supports alternative options such as .site for businesses seeking varied domain structures. For those not ready to purchase permanent domains, the company offers temporary .io domains as part of their managed hosting products.

Managed domain hosting involves purchasing, configuring, connecting, and setting up domain names automatically for their customers. All domain services maintain a flat annual cost structure, with pricing levels capped at triple the initial year's rate, eliminating higher renewal charges common among competitors.

Nexcess maintains stringent policy standards, not servicing hateful or abusive domain names. Additional requirements for specific regional domains like .in or .eu mandate customer residence verification processes. The company also enables domain reselling capabilities, providing free migration services for transferred domains to simplify the transition process.

Advanced Hosting Features and Tools

The Nexcess panel offers a robust suite of advanced features for hosting and management, including CDN integration, container services, logs management, and scheduled tasks. The CDN system supports cache purging through the "What does purge the CDN mean?" feature, enabling precise control over content distribution.

The logs management system provides detailed insights through the Logs Tab, which captures both domain error and transfer logs. This information is accessible via the "Viewing error and access logs in the Nexcess Client Portal" guide, helping users monitor site performance and security.

Scheduled tasks enhance automation through the Scheduled Tasks feature, which allows users to manage cron jobs for their domains. Comprehensive documentation on "How to schedule cron jobs in Nexcess Cloud" supports administrators in setting up regular maintenance and background processes.

Container services represent a significant advancement, particularly for Magento 2 stores. The system supports multiple container options, including Elasticsearch for search functionality and RabbitMQ for message queue purposes. Essential guides on "How to enable Elasticsearch for your Nexcess Cloud account" and "RabbitMQ & Magento 2 on Managed Hosting by Nexcess" provide detailed setup instructions.

Integration services expand functionality through partnerships with tools like New Relic for performance monitoring. The Integrations tab allows seamless connection to external systems, as documented in "Configuring New Relic monitoring" and "How to use New Relic APM with Magento 2."

These advanced tools build upon Nexcess's core strengths in scalability and security. The platform automatically handles traffic spikes through instant autoscaling that bypasses PHP capacity limits. Underpinning this architecture is PHP8+ and Nginx infrastructure, optimized for performance through advanced asset caching and integrated CDN capabilities. Together, these features enable administrators to maintain reliability while optimizing their hosting environment.
